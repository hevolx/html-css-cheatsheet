HTML Cheatsheet

Document structure

<!DOCTYPE html>
<html lang="en">
  <head>...</head>
  <body>...</body>
</html>

the basic skeleton of every HTML page. lang helps screen readers and search engines

<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">

set the character encoding and make the page scale correctly on mobile

<link href="styles.css" rel="stylesheet">

link an external stylesheet (goes in <head>)

Text & links

<h1>...</h1> to <h6>...</h6>

headings, from most to least important. use one <h1> per page

<p>text</p>
<strong>important</strong>
<em>emphasis</em>

paragraph, strong importance (bold) and emphasis (italic)

<a href="[url]">link text</a>

create a link. use #id as the url to jump to an element on the same page

<img src="[file]" alt="[description]">

show an image. always write an alt text

Lists & forms

<ul><li>item</li></ul>
<ol><li>item</li></ol>

unordered (bullets) and ordered (numbers) list

<label for="name">Name</label>
<input id="name" type="text" required>

a text field with a label connected through for and id

<button type="submit">Send</button>

a button. inside a <form> it submits the form

Semantic elements

<header> <nav> <main>
<section> <article> <footer>

elements that describe the meaning of the content, better than a pile of <div>s

CSS Cheatsheet

Selectors

p { }   .class { }   #id { }

select by element, class or id

ul li { }   ul > li { }   a:hover { }

descendant, direct child and the hover state

Box model & layout

margin: 1em;
padding: 1em;
border: 1px solid black;

space outside, space inside and the border of an element

box-sizing: border-box;

include padding and border in the element's width and height

display: flex;
justify-content: center;
align-items: center;
gap: 1em;

flexbox: lay out children in a row and center them with spacing

display: grid;
grid-template-columns: repeat(3, 1fr);

grid: three equally wide columns

Text & color

color: #333;
background-color: whitesmoke;

text color and background color

font-family: "Lucida Grande", sans-serif;

font list. the browser uses the first one available

@font-face {
  font-family: "MyFont";
  src: url("myfont.woff2");
}

load your own font file

@media (max-width: 600px) { }

apply styles only on screens that are 600px wide or less

JavaScript Cheatsheet

Variables & functions

const name = "Ada";
let count = 0;

const can't be reassigned, let can. avoid var

function add(a, b) { return a + b; }
const add = (a, b) => a + b;

a function declaration and the same as an arrow function

`Hello ${name}!`

template literal: put variables straight into a string

Control flow

if (x > 0) { } else { }

run code depending on a condition. compare with ===

for (let i = 0; i < 5; i++) { }
for (const item of list) { }

a counting loop and a loop over every item in a list

Arrays & objects

list.push(x)   list.length

add an item at the end, and get the number of items

list.map(x => x * 2)
list.filter(x => x > 1)

make a new list by transforming or filtering every item

const user = { name: "Ada", age: 36 };
user.name

an object with properties, read with dot notation

DOM Cheatsheet

Selecting elements

document.querySelector(".class")

get the first element matching a CSS selector

document.querySelectorAll("li")

get all matching elements

document.getElementById("id")

get an element by its id

Changing elements

el.textContent = "New text";

change the text of an element (safe, no HTML parsing)

el.classList.add("active");
el.classList.toggle("hidden");

add a class, or add/remove it depending on whether it exists

const li = document.createElement("li");
list.append(li);

create a new element and put it in the page

Events

button.addEventListener("click", (event) => {
  console.log("clicked");
});

run a function when the user clicks. works for submit, input, keydown and more

Git Cheatsheet

Stage & Snapshot

git status

show modified files in working directory, staged for your next commit

git add [file]

add a file as it looks now to your next commit (stage)

git commit -m "[message]"

commit your staged content as a new commit snapshot

Branching & Merging

git branch

list your branches. a * will appear next to the currently active branch

git branch -M main

renames the current branch (usually master) to main

git branch [branch-name]

create a new branch at the current commit

git checkout [branch-name]

switch to another branch and check it out into your working directory

git merge [branch-name]

merge the specified branch’s history into the current one

git log

show all commits in the current branch’s history

Share & Update

git remote add [alias] [repository-url]

add a git URL as an alias

git fetch [alias]

fetch down all the branches from that Git remote

git push [alias] [branch-name]

transmit local branch commits to the remote repository branch

git push --set-upstream origin main

sets it as the upstream tracking branch for future pushes and pulls
